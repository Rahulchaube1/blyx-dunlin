# Dunlin starter

Audit a table export for duplicate parents and orphaned child rows.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Dunlin** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
0
1
2
1
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/dunlin) · [View the release](https://github.com/Rahulchaube1/blyx-dunlin/releases/tag/v0.1.0)
